1. **Алгоритм Боєра-Мура:** 
З огляду на отримані нижче результати цей метод демонструє найкращі результати при пошуку реального, так і неіснуючого підрядка. Пошук відбувається методом порівняння останнього символа патерну з поточним символом підрядка.

2. **Алгоритм Кнута-Морріса-Пратта:** 
З огляду на отримані нижче результати у даному порівнянні цей метод для мене посів другу сходинку. Єповільнішим за Боєра-Мура, але швидчим за Рабіна-Карпа.

3. **Алгоритм Рабіна-Карпа**
